# 🐧 企鹅开场白助手 v2.0

一个 SillyTavern（酒馆）酒馆助手脚本，把「开场白选择器」和「返回开场页」合进同一份脚本：既能一键弹窗切换任意开场白，也能在第 0 楼停在其他页时一键回到开场页。

> v2.0 = 企鹅简易开场白选择器 v1.0（作者：西维纳尔）+ 返回开场页-角色卡简易模板（企鹅的酒馆开场页生成器生成）。
> 两个入口相互独立，任一失效不影响另一个；v1.0 选择器仍保留在本仓库，已在使用的人可以继续导入。

---

## ✨ 功能一览

**入口一：脚本按钮「开场白选择」**

- 📋 **开场白总览**：自动读取当前角色卡的 `first_messages`，在弹窗中以列表形式展示所有卡片自带开场白
- 👀 **预览文本**：每条开场白显示前 120 字预览，自动剥离 HTML 标签、图片占位显示为 `[图片]`
- ⚡ **一键切换**：点击列表项即切换第 0 楼到对应开场白
- 🔄 **自动同步**：卡片开场白未出现在当前聊天时，自动补齐进第 0 楼的 swipes（只补不删），且保留你当前选中的页面
- 🎲 **re-roll 友好**：如果你用箭头重 roll 过自定义开局，弹窗顶部会显示「★ 当前 · 非卡片开场白」提示项
- 🎨 **主题适配**：界面配色跟随酒馆主题变量（SmartTheme），深浅色主题都能正常显示

**入口二：正文末尾的「← 返回开场页」按钮**

- ⬅️ **自动出现**：第 0 楼当前页不是第 1 张（开场页）时，正文末尾自动出现按钮，包含第 2 张及以后的开场白和你 re-roll 出的自定义页
- 🖱️ **一键回开局**：点击立即切回第 1 张开场白，按钮随之消失
- 🔇 **音轨联动**：切回时顺带停掉并移除开场白联动音轨（本工具挂载的 `data-opg-greet-audio`），视为重新开局
- 🧹 **不污染正文**：只做界面注入，不改聊天文本、不碰其它楼层、不使用正则

## 📦 安装方法

1. 确保已安装 **酒馆助手（JS-Slash-Runner / Tavern Helper）** 扩展并启用
2. 下载本仓库中的 `酒馆助手脚本-企鹅开场白助手 v2.0.json`
3. 打开酒馆 → 左上角「扩展」→ 酒馆助手 → 脚本库，点击「导入脚本」，选择该 JSON 文件
4. 在脚本库中确认「企鹅开场白助手 v2.0」处于启用状态
5. 聊天界面上方会出现「开场白选择」按钮；当第 0 楼不在开场页时，正文末尾会出现「← 返回开场页」按钮

## 📖 使用示例

- **场景一：挑选开局**
  导入了一张有 5 个开场白的角色卡，点击「开场白选择」按钮，弹窗列出全部 5 个开局及预览 → 点击想要的开局 → 提示「已切换到开场白 3」→ 第 0 楼内容立即更换。

- **场景二：换开局不丢进度**
  已经聊了 200 楼想回看重 roll 的其他开局？直接打开弹窗切换即可，后续楼层不受影响。

- **场景三：重 roll 后反悔**
  手滑把第 0 楼重 roll 成了随机内容？打开弹窗，顶部「★ 当前 · 非卡片开场白」下面就是原版卡片开场白列表，点一下就切回来。

- **场景四：一键回开场页**
  现在停在第 3 张开场白，想回到角色卡封面那版开场白？直接点正文末尾的「← 返回开场页」，第 0 楼切回第 1 张，按钮自动消失。

## ❓ QA

**Q：按钮不见了？**
A：请检查酒馆助手是否已安装并更新到较新版本，以及本脚本是否在脚本库中启用。

**Q：弹窗提示「当前角色卡没有开场白」？**
A：当前角色卡的 `first_mes` 为空或多开场白数据缺失，请先在角色卡中编辑开场白。

**Q：切换后正文没变化？**
A：请刷新页面后重试；若仍无效，可能是其他前端脚本冲突，可尝试单独禁用排查。

**Q：楼层里出现了两个「← 返回开场页」按钮？**
A：说明该角色还单独启用了开场页生成器生成的「返回开场页」脚本，两者都会往第 0 楼注入按钮，停用其一即可。

**Q：「← 返回开场页」按钮什么时候出现？**
A：只在第 0 楼当前页不是第 1 张（开场页）时出现；切回第 1 张后按钮自动消失，不影响正文内容。

**Q：会修改我的聊天记录吗？**
A：本脚本只会读写第 0 楼的 swipes（消息页）数据，用于同步和切换开场白，不会改动其他楼层的正文；「返回开场页」按钮为界面注入，不写入消息文本。

**Q：支持群聊吗？**
A：目前仅针对普通单人聊天的第 0 楼设计，群聊场景未做适配。
